# LinePilot website

Simple, dependency-free product website and public Privacy Policy for LinePilot.

## Pages

- `index.html` — product overview, beta information and planned Free/Pro model
- `privacy.html` — public privacy policy for Google Play

## Local preview

Open `index.html` directly, or serve the folder with any static web server.

## GitHub Pages

The included workflow publishes the repository root to GitHub Pages whenever `main` is updated.
